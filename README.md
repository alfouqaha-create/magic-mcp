# نظام درجات الطلاب

موقع (Node.js + Express + PostgreSQL على Neon) ينشئ فيه الطالب حساباً بنفسه (رقم أكاديمي + اسم + كلمة سر يختارها) ثم يدخل ليرى درجاته في كل مقرر: الملاحظة الصفية، ملف الطالب، المهام، الاختبارات، المجموع الكلي، درجة التقويم التكويني (من 40)، والامتحان النهائي العملي.

## الصفحات
- `/` واجهة الطالب: تبويب «حساب جديد» (مرة واحدة) وتبويب «دخول».
- `/teacher` لوحة المعلم: رفع ملفات Excel (استمارة التقويم التكويني)، عرض الشعب والطلاب وحالة حساب كل طالب، إعادة تعيين كلمة سر طالب، حذف شعبة.

## المتغيرات المطلوبة
| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط قاعدة Neon (إلزامي) |
| `ADMIN_PASSWORD` | كلمة مرور المعلم (إلزامية لتفعيل `/teacher`) |

## حسابات الطلاب
- **حساب جديد (مرة واحدة):** الرقم الأكاديمي + الاسم الثلاثي للتحقق + كلمة سر (6 أحرف فأكثر). يُقبل الاسم كبداية اسم الطالب في الكشف (الأول + الأب + الجد)، أو الأول + الأب + العائلة، ويتجاهل الفروق الإملائية (أ/ا، ة/ه، ى/ي، عبد الله/عبدالله).
- **الدخول:** الرقم الأكاديمي + كلمة السر.
- كلمات السر تُخزَّن مشفّرة (scrypt مع salt)، ولا يستطيع المعلم رؤيتها. نسيها الطالب؟ من `/teacher` اضغط «إعادة تعيين» أمام اسمه فينشئ كلمة سر جديدة.
- حماية من التخمين: 8 محاولات خاطئة لكل رقم أكاديمي كل 15 دقيقة، و30 لكل جهاز.
- إن كان اسم طالب فارغاً في Excel فسيظهر «طالب + الرقم» ولن يستطيع التسجيل حتى يُكمَّل الاسم ويُعاد رفع الملف.

## طريقة الحساب (مطابقة لصيغ ملف Excel)
- المجموع الكلي = الملاحظة الصفية + ملف الطالب + المهام + الاختبارات (من 100).
- درجة التقويم التكويني = `MROUND(المجموع / 2.5, 0.5)` (من 40).
- الامتحان النهائي العملي يُعرض كما هو (من 20) ويظهر «لم تُرصد بعد» إن كان فارغاً.

## تحديث الدرجات
ارفع الملف المحدّث من `/teacher`؛ رفع شعبة موجودة (نفس المقرر والشعبة) يستبدل درجاتها كاملة. بيانات الطلاب لا تُخزَّن في GitHub، فقط في Neon.

## التشغيل محلياً
```bash
npm install
DATABASE_URL="postgresql://..." ADMIN_PASSWORD="كلمة-مرور" npm start
```
ثم افتح http://localhost:3000

## النشر على Render
- Web Service، Build: `npm install`، Start: `npm start`
- أضف `DATABASE_URL` و`ADMIN_PASSWORD` من تبويب Environment.
- الجداول `sections` و`grades` تُنشأ تلقائياً.
